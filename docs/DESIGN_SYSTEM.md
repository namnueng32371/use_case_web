## 3. ตัวอักษร

**ค่าปัจจุบัน**
- ฟอนต์หลัก **IBM Plex Sans Thai** (Google Fonts น้ำหนัก 400/500/600/700) สำรอง `-apple-system, sans-serif` ใช้กับ body และ SVG ไดอะแกรม
- Word export ใช้ **Arial** (Word ไม่โหลด Google Fonts) ค่าคงที่ n8n node type ใช้ `monospace`
- ขนาดที่ใช้บ่อย: 12 / 13 / 12.5 / 11 / 11.5px (เนื้อหาทั่วไป 13px) ข้อความย่อย 10–11px

- `letter-spacing:-0.015em` ใช้เฉพาะ h1 ภาษาอังกฤษ

**ปัญหาที่พบ**
- มี `font-weight:800` (`.score-chip-num`, `.dg-warn-text`) แต่โหลดฟอนต์สูงสุดแค่ 700 เบราว์เซอร์จะใช้ 700 แทน

**ข้อเสนอแนะ**
- ห้ามใช้ tracking ติดลบกับข้อความไทย (วรรณยุกต์จะชนกัน)

## 6. สถานะฟีดแบ็ก

**ค่าปัจจุบัน**
- **ข้อผิดพลาดในฟอร์ม:** `.error-msg` ตัวแดง 12px ซ่อนไว้จนกว่าจะเกิดปัญหา (เช่น ไม่กรอกชื่อ)
- **สำเร็จ/ข้อความสถานะ:** `.status` สีเขียว teal 12px ("บันทึกแล้ว"); ล้มเหลวเปลี่ยนเป็นสีแดง
- **ยืนยันการลบ:** แสดงในบรรทัดเดียวกับปุ่ม ("ลบ? ใช่ / ไม่") ไม่เปิด modal
- **ข้อมูลไม่ครบ:** ป้ายแดงแทนคะแนนในการ์ด และข้อความสรุปในฟอร์ม (`#score-preview`)
- **คำเตือนเฉพาะช่อง:** ผู้ใช้พร้อมกันสูงเกินผู้ใช้ต่อวัน แสดงข้อความแดงใต้ช่อง
- **ผลวิเคราะห์ล้าสมัย:** กล่องสีเหลืองอำพัน `.spec-stale`
- **สถานะว่าง:** `.empty` กล่องเส้นประพร้อมข้อความแนะนำให้เพิ่ม use case
- **ข้อผิดพลาดจาก AI:** แสดงข้อความภาษาไทยจาก `sampleErrorMessage()` (เช่น ไม่ได้รับอนุญาต เรียกถี่เกินไป หมดเวลา)
- **Disabled:** มีเฉพาะปุ่ม "ล้างทั้งหมด" (ความทึบ 50% และ tooltip อธิบายเหตุผล)
- **Hover/Focus:** ปุ่ม แท็บ การ์ด มี hover; focus ใช้ `:focus-visible` เส้น 2px สี teal ทั้งหน้า

**ที่ยังไม่มี:** ไม่มี spinner/skeleton (สถานะโหลดเป็นข้อความ) ไม่มี toast ไม่มี `@keyframes`

**ข้อเสนอแนะ:** กำหนดรูปแบบมาตรฐานเดียวสำหรับ loading/success/error ของงาน AI และใช้ Token `--danger` แทนค่าฝังตรง

## 7. ไอคอนและภาพ

**ค่าปัจจุบัน**
- ไอคอนเป็น **inline SVG แบบ Lucide** (viewBox 24, stroke 2, ปลายมน, ขนาด 14px) เก็บใน object `ICONS` (10 ตัว) และฝังตรงในแท็บ ไม่มี icon font
- ภาพ: โลโก้ Polymate (PNG data URI) มาร์ก footer (SVG) ภาพแนบของ use case (เก็บเป็น base64 ขนาดไม่เกิน 10MB)
- กราฟใช้ Chart.js (CDN `cdnjs`) ไดอะแกรมเป็น SVG เขียนมือ

**ปัญหาที่พบ:** หน้า Flow และบางข้อความใช้ emoji (🚫 👤 🖥️) แทนไอคอน ซึ่งไม่สอดคล้องกับชุดไอคอน SVG

**ข้อเสนอแนะ:** เปลี่ยน emoji เป็นไอคอน SVG ชุดเดียวกัน กำหนดขนาดมาตรฐาน (14 / 16 / 20px)

## 8. การตอบสนองและความเข้าใจ (Responsive Design & Accessibility)

**Responsive — ค่าปัจจุบัน**
- แนวทาง desktop-first เน้น PC; breakpoint `max-width` 600px (3 จุด) · 640px (4 จุด) · 720px (1 จุด)
- Container ขยายตามจอได้ถึง 1400px; แท็บ wrap ได้; ฟอร์ม 2 คอลัมน์ยุบเป็น 1 ที่ ≤600px
- ไดอะแกรม SVG กว้างขั้นต่ำ 1380px เลื่อนแนวนอนได้พร้อมปุ่มซูม; ตารางแผนงานเลื่อนแนวนอนได้
- มี `@media print` สำหรับพิมพ์เอกสาร/แผนงาน/Flow จาก modal
- ยังไม่ได้ทดสอบบนอุปกรณ์จริง (ต้องยืนยัน) และ **ยังไม่ทราบ** ว่าต้องรองรับมือถือในระดับไหน

**Accessibility — ค่าปัจจุบัน**
- แท็บใช้ `role="tablist"` / `role="tab"` และอัปเดต `aria-selected` เมื่อสลับ
- ปุ่มไอคอนมี `aria-label` (10 จุด) ไอคอนตกแต่งมี `aria-hidden` ภาพมี `alt` ข้อความสถานะบันทึกมี `aria-live`
- ช่องกรอกผูก `label for=` ครบ มี `:focus-visible` ทั้งหน้า
- `lang="th"` มีเฉพาะไฟล์ local (`AI_Use_Case_Program12.html`) ส่วน `artifact.html` เป็น fragment ให้แพลตฟอร์มห่อ (ต้องยืนยันว่า Artifact ตั้ง `lang` ให้)

**Accessibility — ช่องว่างที่พบ**
- Modal ไม่มี `role="dialog"` / `aria-modal` ไม่มีการดักโฟกัส และไม่มีการปิดด้วยปุ่ม Esc (ไม่พบ handler `keydown`)
- แท็บไม่มี `role="tabpanel"` และ `aria-controls`
- ไม่มี `prefers-reduced-motion` (มี transition 13 จุด ไม่มี animation)
- สีข้อความรองบนพื้น `--bg` ต่ำกว่า 4.5:1 (ดูหัวข้อ 2)

**ข้อเสนอแนะ:** เพิ่ม `role="dialog"` + Esc + focus trap ให้ modal ทั้ง 4 ตัว, `tabpanel`/`aria-controls` ให้แท็บ, และตรวจ contrast ทั้งหน้าด้วยเครื่องมือก่อนปิดเฟส redesign
