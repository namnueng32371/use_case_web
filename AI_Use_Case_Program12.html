AI use case prioritization tool

บันทึก ให้คะแนน จัดลำดับความสำคัญ และออกเอกสารสรุปของ use case AI ในองค์กร — ในโปรแกรมเดียว

ดูเกณฑ์การแนะนำประเภท AI ทั้งหมด
ตามชนิดข้อมูล/งาน
ข้อความ / ภาษา → NLP และ LLM (แชทบอท, สรุปเอกสาร)
รูปภาพ / วิดีโอ → Computer vision (ตรวจคุณภาพสินค้า, OCR)
เสียง → Speech AI (แปลงเสียงเป็นข้อความ)
ตัวเลข / time series → Predictive ML (พยากรณ์ยอดขาย)
งานทำซ้ำ มีกฎตายตัว → RPA ผสาน AI (คีย์ข้อมูลอัตโนมัติ)
ต้องการเนื้อหาใหม่ → Generative AI (สร้าง draft เนื้อหา/ภาพ)
ต้องการแนะนำ/จับคู่ → Recommendation AI (แนะนำสินค้า, จับคู่งาน)
งานเฉพาะทาง
สร้างภาพจากคำสั่ง → Image generation (ภาพโฆษณา, ภาพสินค้า)
ค้นหา/ถามตอบจากเอกสาร → Embedding / RAG (ถามตอบจากคลังเอกสารองค์กร)
ผู้ช่วยความรู้ภายในองค์กร → Knowledge assistant (ช่วยพนักงานค้นข้อมูล)
ปรับโมเดลเฉพาะองค์กร → Fine-tuning (ปรับโมเดลให้เข้าใจศัพท์เฉพาะ)
ประมวลผลข้อมูลจำนวนมาก → Batch inference (จัดหมวด/วิเคราะห์ข้อมูลก้อนใหญ่)
พยากรณ์ความต้องการสินค้า → Demand forecasting (วางแผนสต็อก/จัดซื้อ)
คาดการณ์การซ่อมบำรุง → Predictive maintenance (เครื่องจักร, IoT)
ตรวจจับความผิดปกติ/ทุจริต → Anomaly detection (fraud, ความปลอดภัย)
งานอัตโนมัติหลายขั้นตอน → AI agent / automation (เชื่อมหลายระบบ)

เพิ่ม use case ใหม่

กรุณากรอกชื่อ use case
กรุณากรอก แผนก, ผู้รับผิดชอบ และ ปัญหาทางธุรกิจ ให้ครบ
รองรับ PDF, รูปภาพ, Word, Excel ขนาดไม่เกิน 10MB (เก็บฝังในโปรแกรม) — หากเกิน ให้กรอกลิงก์/ชื่ออ้างอิงด้านล่างแทน
การอ้างอิงกระบวนการคุณภาพ (QWP / Control / KQI) *จำเป็น
กรุณากรอกข้อมูลในกลุ่มการอ้างอิงกระบวนการคุณภาพ (QWP / Control / KQI) ให้ครบทุกช่อง
3
1 = ผลกระทบน้อยมาก  →  5 = ผลกระทบสูงมากต่อธุรกิจ
3
1 = ทำได้ยากมาก  →  5 = ทำได้ง่าย เทคโนโลยีพร้อม
3
1 = แทบไม่มีข้อมูล  →  5 = ข้อมูลพร้อม สะอาด ครบถ้วน
3
1 = เสี่ยง/ซับซ้อนน้อยมาก  →  5 = เสี่ยง/ซับซ้อนสูงมาก
Spec, ความเสี่ยง, ทรัพยากร และ kQI (ไม่บังคับ, ระบบคำนวณอัตโนมัติ)

เปรียบเทียบคะแนนความสำคัญ

สูตรคะแนน: (ผลกระทบทางธุรกิจ × 0.35) + (ความเป็นไปได้ทางเทคนิค × 0.25) + (ความพร้อมของข้อมูล × 0.25) + ((6 − ความเสี่ยง) × 0.15) แล้วคูณ 20 เพื่อแปลงเป็นคะแนนเต็ม 100 — คะแนน ≥75 = ระดับสูง, 50–74 = ระดับกลาง, ต่ำกว่า 50 = ระดับต่ำ
กดปุ่ม "เอกสาร" บนการ์ดแต่ละ use case เพื่อดูเอกสารสรุปฉบับเต็ม (รวม Spec Hardware, ความเสี่ยง, ทรัพยากร, KQI และ ROI) แล้วเลือกดาวน์โหลดเป็นไฟล์ Word หรือพิมพ์/บันทึกเป็น PDF ได้ทันที
กดปุ่ม "แผนงาน" เพื่อแปลง Flow ขั้นตอนการทำ AI เป็นแผนงานละเอียด (กิจกรรม ช่วงเวลา ผู้รับผิดชอบ สิ่งส่งมอบ และไทม์ไลน์ Gantt) โดยระบบกระจายระยะเวลาตามที่ระบุในช่อง "ทรัพยากรและประมาณการ" ให้อัตโนมัติ
ในฟอร์ม กดปุ่ม "เติม Spec แนะนำตามประเภท AI อัตโนมัติ" เพื่อให้ระบบเติม Spec hardware ความเสี่ยง ทรัพยากร KQI และ ROI ที่เหมาะกับประเภท AI นั้นให้ แล้วปรับแก้ได้ตามจริง
ข้อมูลจะถูกบันทึกไว้ในฐานข้อมูลกลาง (MySQL) ผู้ใช้ทุกคนที่เข้าเครื่องมือนี้จะเห็นข้อมูลชุดเดียวกัน

โครงสร้างทีม AI Star พร้อมหน้าที่รับผิดชอบของแต่ละตำแหน่ง — สรุปจากไฟล์ "โครงการ AI Local GSK.xlsx" ชีท "โครงสร้างทีมสร้าง AI Star" กดที่ตำแหน่งเพื่อดู Job Description ฉบับเต็ม

แผนภาพละเอียด: ลำดับขั้นตอน Output → Input ระหว่างตำแหน่ง (1–22)

ขั้นตอนการทำงานของ AI Unit ตั้งแต่ฝ่ายธุรกิจเสนอ Use Case จนถึงใช้งานจริง — สรุปจากไฟล์ "โครงการ AI Local GSK.xlsx" ชีท "Flow การทำงาน AI Start" ระบุตำแหน่งผู้รับผิดชอบในแต่ละขั้นตอนตามชีทโครงสร้างทีมเดียวกัน
